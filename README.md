# Brew & Bean

Brew & Bean is a modern, responsive coffee shop website built with plain HTML, CSS, and JavaScript. The project presents the cafe’s brand through a polished set of pages for the homepage, menu, about us, and contact information.

## Project Overview

This website is designed to feel warm, calm, and welcoming, reflecting the atmosphere of a neighborhood coffee shop. It includes:

- A hero section on the homepage with clear call-to-action buttons
- A menu page showcasing coffee, tea, and food offerings
- An about page describing the cafe’s story and values
- A contact page with location, hours, and contact details
- Responsive styling and simple interactive effects

## Project Structure

- index.html - Home page
- menu.html - Menu page
- about.html - About Us page
- contact.html - Contact page
- css/style.css - Main stylesheet
- js/script.js - Interactive behavior for navigation and animations
- assets/images - Image assets used across the site

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

Because this is a static website, you can open the project directly in a browser:

1. Open the project folder in your code editor.
2. Launch index.html in your browser.
3. Alternatively, use a live server extension for a smoother preview experience.

## Notes

No build tools or package installation are required. The site works as a simple static web project.
